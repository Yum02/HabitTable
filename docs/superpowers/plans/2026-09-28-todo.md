# 할 일(To-do) 기능 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 습관과 별개인 일회성 "할 일" 목록을 별도 탭으로 추가한다 (추가·수정·삭제·완료 토글, 미완료가 위·완료가 아래).

**Architecture:** 정렬·제목 정리 규칙은 SwiftData 없는 순수 함수(`TodoProgress`)로 두고 단위 테스트한다. 저장은 독립된 새 `@Model TodoItem`(Habit과 관계 없음). 화면은 `TodoListView`(List + 스와이프)와 `TodoEditorView`(시트)이고, `ContentView`를 `TabView`로 바꿔 습관/할 일 두 탭을 만든다.

**Tech Stack:** Swift, SwiftUI, SwiftData, XCTest, XcodeGen, GitHub Actions(macOS 러너)

**Spec:** `docs/superpowers/specs/2026-09-28-todo-design.md`

## Global Constraints

- 최소 iOS 17. `project.yml`의 `sources: [HabitTable]` / `[HabitTableTests]`가 폴더째 포함하므로 새 파일은 `project.yml` 수정 없이 자동 포함된다.
- UI 문구는 모두 한국어 해요체.
- 색은 `Theme`의 토큰만 쓴다 (`Theme.soil`, `Theme.stem`, `Theme.card`, `Theme.grass3`, `Theme.grass4`, `Theme.meadow`, `Theme.background`). 새 색 추가 금지.
- 글꼴은 `.font(.spoqa(크기, .bold, relativeTo: .body))` 형태.
- 앱은 라이트 모드 고정(`.preferredColorScheme(.light)`)이고 다크 모드는 범위 밖이다.
- `TodoItem`은 `Habit`과 관계를 맺지 않고 `DayKey`/`HabitSchedulable`을 쓰지 않는다.
- 계산 로직은 순수 함수 + 테스트를 먼저 작성한다. 테스트는 SwiftData 없이 프로토콜을 따르는 가짜 구조체로 쓴다.
- `.xcodeproj`는 커밋하지 않는다.
- **로컬에서 Xcode 빌드·테스트가 불가능하다(Windows).** 확인은 push 후 GitHub Actions로 한다: `gh run watch`, 실패 시 `gh run view --log-failed`, 스크린샷은 `gh run download -n screenshots`. 그래서 컴파일 가능성을 특히 꼼꼼히 확인한다(import, 접근 제어, 이름 일치).
- 커밋 메시지는 한국어, 끝에 다음 줄을 붙인다: `Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>`

## Review Focus

스펙이 말하지 않았지만 사용자가 만날 가능성이 큰 입력·상황 (가능성 순):

1. 공백·줄바꿈만 입력해서 **새 항목 저장** → 저장되지 않고 저장 버튼이 비활성화되어야 한다. (Task 1 `normalizedTitle` 테스트, Task 3 `canSave`)
2. 기존 항목을 수정하면서 이름을 **공백만 남기고 저장** → 기존 제목을 빈 문자열로 덮어쓰면 안 된다. (Task 1 테스트, Task 3 `save()` 가드)
3. 두 항목의 **`createdAt`이 완전히 같음** → 결과 순서가 입력 순서로 유지되어야 한다(깜빡이며 뒤바뀌지 않음). (Task 1 테스트)
4. **완료했다가 다시 되돌림** → 항목이 원래 자리(생성순)로 돌아와야 한다. (Task 1 테스트)
5. **아주 긴 제목** → 잘리지 않고 여러 줄로 줄바꿈되어야 한다. 마지막 항목을 지우면 빈 상태 카드로 돌아와야 한다. (Task 2 샘플 데이터에 긴 제목 포함 → Task 4 스크린샷으로 확인, Task 3 `items.isEmpty`는 정렬 전 `@Query` 결과로 판정)

```swift
            todo("c", done: true, at: 30),

        XCTAssertEqual(names(TodoProgress.sorted(items)), ["a", "b", "c"])

        XCTAssertEqual(names(TodoProgress.sorted(items)), ["b", "c", "a"])
```

`HabitTable/TodoProgress.swift`:

```swift
import Foundation

/// 정렬에 필요한 값만 노출하는 프로토콜 (테스트에서 SwiftData 없이 쓰기 위함)
protocol TodoSortable {
    var isDone: Bool { get }
    var createdAt: Date { get }
}

/// 할 일의 순수 계산 규칙 — 테스트 대상
enum TodoProgress {
    /// 미완료가 위, 완료가 아래. 각 그룹 안에서는 만든 순서대로.
    /// 만든 시각이 같으면 입력 순서를 유지한다(Swift 표준 정렬은 실제로 안정적이다).
    static func sorted<T: TodoSortable>(_ items: [T]) -> [T] {
        items.sorted { a, b in
            if a.isDone != b.isDone { return !a.isDone }
            return a.createdAt < b.createdAt
        }
    }

    /// 앞뒤 공백·줄바꿈을 지운 제목. 비어 있으면 nil(저장 불가).
    static func normalizedTitle(_ raw: String) -> String? {
        let trimmed = raw.trimmingCharacters(in: .whitespacesAndNewlines)
        return trimmed.isEmpty ? nil : trimmed
    }
}
```

```swift
import SwiftUI
import SwiftData

/// 할 일 추가·수정 시트 (HabitEditorView의 축소판: 이름 입력칸 하나)
struct TodoEditorView: View {
    @Environment(\.dismiss) private var dismiss
    @Environment(\.modelContext) private var context

    /// nil이면 새 할 일
    let todo: TodoItem?

    @State private var title: String
    @FocusState private var titleFocused: Bool

    init(todo: TodoItem?) {
        self.todo = todo
        _title = State(initialValue: todo?.title ?? "")
    }

    private var canSave: Bool {
        TodoProgress.normalizedTitle(title) != nil
    }

    var body: some View {
        NavigationStack {
            ScrollView {
                VStack(alignment: .leading, spacing: 8) {
                    Text("내용")
                        .font(.spoqa(13, .bold, relativeTo: .footnote))
                        .foregroundStyle(Theme.stem)
                        .padding(.horizontal, 4)
                    TextField("예: 병원 예약 전화하기", text: $title, axis: .vertical)
                        .font(.spoqa(17, .regular, relativeTo: .body))
                        .foregroundStyle(Theme.soil)
                        .focused($titleFocused)
                        .submitLabel(.done)
                        .padding(.horizontal, 16)
                        .padding(.vertical, 13)
                        .background(RoundedRectangle(cornerRadius: 14, style: .continuous).fill(Theme.card))
                }
                .padding(16)
            }
            .background(Theme.meadow.ignoresSafeArea())
            .navigationTitle(todo == nil ? "새 할 일" : "할 일 수정")
            .navigationBarTitleDisplayMode(.inline)
            .toolbar {
                ToolbarItem(placement: .cancellationAction) {
                    Button("취소") { dismiss() }
                        .foregroundStyle(Theme.stem)
                }
                ToolbarItem(placement: .confirmationAction) {
                    Button("저장", action: save)
                        .font(.spoqa(17, .bold, relativeTo: .body))
                        .disabled(!canSave)
                }
            }
            .onAppear { if todo == nil { titleFocused = true } }
        }
        .tint(Theme.grass4)
        .presentationDetents([.medium, .large])
    }

    private func save() {
        // 공백만 남긴 수정이 기존 제목을 빈 문자열로 덮어쓰지 못하게 막는다
        guard let trimmed = TodoProgress.normalizedTitle(title) else { return }
        if let todo {
            todo.title = trimmed
        } else {
            context.insert(TodoItem(title: trimmed, isDone: false, createdAt: .now))
        }
        dismiss()
    }
}
```

`HabitTable/TodoListView.swift`:

```swift
import SwiftUI
import SwiftData

/// 시트 종류: 새 항목 / 기존 항목 수정
enum TodoEditorTarget: Identifiable {
    case new
    case edit(TodoItem)

    var id: String {
        switch self {
        case .new:
            return "new"
        case .edit(let item):
            return "edit-\(item.persistentModelID)"
        }
    }

    var todo: TodoItem? {
        switch self {
        case .new:
            return nil
        case .edit(let item):
            return item
        }
    }
}

/// 할 일 탭: 미완료가 위, 완료(취소선)가 아래
struct TodoListView: View {
    @Environment(\.modelContext) private var context
    @Query(sort: \TodoItem.createdAt) private var items: [TodoItem]
    @State private var editorTarget: TodoEditorTarget?

    private var sortedItems: [TodoItem] {
        TodoProgress.sorted(items)
    }

    var body: some View {
        Group {
            if items.isEmpty {
                ScrollView {
                    emptyCard
                        .padding(.horizontal, 16)
                        .padding(.top, 8)
                }
            } else {
                List {
                    ForEach(sortedItems) { item in
                        row(item)
                            .listRowBackground(Theme.card)
                    }
                }
                .scrollContentBackground(.hidden)
            }
        }
        .background(Theme.background)
        .navigationTitle("할 일")
        .navigationBarTitleDisplayMode(.inline)
        .toolbar {
            ToolbarItem(placement: .topBarTrailing) {
                Button {
                    editorTarget = .new
                } label: {
                    Image(systemName: "plus")
                }
                .accessibilityLabel("할 일 추가")
            }
        }
        .sheet(item: $editorTarget) { target in
            TodoEditorView(todo: target.todo)
        }
    }

    // MARK: - 행

    private func row(_ item: TodoItem) -> some View {
        HStack(alignment: .top, spacing: 12) {
            Button {
                withAnimation(.easeInOut(duration: 0.25)) {
```
