# 연속 기록 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 습관마다 오늘 기준 연속 기록(요일 습관=일, 주 n회=주)을 계산해 이번 주 표의 이름 옆에 `🌱5` 배지로 보여 준다.

**Architecture:** 계산은 `HabitProgress`의 순수 함수 `streak`(+ 표시용 `streakBadge`, `streakSpoken`)에 두고 가짜 습관 구조체로 테스트한다. 데이터 모델은 바꾸지 않는다. `WeekMatrixView`는 이 함수를 불러 이름 옆 배지와 접근성 라벨만 덧붙인다.

**Tech Stack:** Swift · SwiftUI · XCTest, iOS 17. 로컬 빌드 불가(Windows) — 검증은 push 후 GitHub Actions(`.github/workflows/ios.yml`)의 단위 테스트와 스크린샷.

**Spec:** `docs/superpowers/specs/2026-10-06-streak-design.md`

**선행 조건:** "주 n회 목표"(`docs/superpowers/plans/2026-10-06-weekly-target.md`)가 끝나고 리뷰를 통과한 뒤 시작한다. 같은 브랜치(`feature/weekly-target`)에서 `WeekMatrixView.swift`, `HabitProgress.swift`를 이어서 고친다.

## Global Constraints

- 날짜는 `DayKey`(정수)로 비교한다. 날짜 이동은 `calendar.date(byAdding:…)`만 쓴다. 86400초 빼기 금지.
- 요일 번호: 일=1, 월=2 … 토=7. 주는 월~일(`HabitProgress.weekDates`).
- 색은 `Theme` 토큰만. 글꼴은 `.font(.spoqa(크기, 굵기, relativeTo: …))`.
- 저장하는 값을 추가하지 않는다. 방식·요일·목표를 바꾸면 남은 `completedDays`로 지금 설정대로 다시 계산한다.
- 배지는 연속 2 이상일 때만 `"🌱\(n)"`(단위 없음). 접근성은 `"5일 연속"` / `"3주 연속"`.
- 배지는 보고 있는 주와 관계없이 **오늘 기준**.
- UI 문구는 한국어 해요체.
- 코드를 바꾸면 컴파일 가능성을 특히 꼼꼼히 확인한다(로컬에서 못 돌림).

## Review Focus

1. **오늘이 쉬는 요일인데 체크돼 있음** → 연속에 더하지 않고 건너뛴다. (Task 1 `testStreakDailyIgnoresRestDayChecks`)
2. **어제(해야 하는 날)를 놓치고 오늘 완료** → 1. "오늘 미완료면 건너뜀"이 어제까지 번지면 안 된다. (Task 1 `testStreakDailyBreaksOnMissedDay`)
3. **연말을 넘는 연속** → 12/31 → 1/1, 12/28~1/3 한 주. (Task 1 `testStreakDailyAcrossYearEnd`, `testStreakWeeklyAcrossYearEnd`)
4. **주 중간에 만든 주 n회 습관** → 만든 주는 목표 n 그대로라 못 채우면 연속에 안 들어간다, 만든 날 이전 기록은 무시. (Task 1 `testStreakWeeklyCreatedMidWeek`)
5. **요일·목표 수정 후 다시 계산** → 같은 기록이 새 설정으로 다르게 나온다. (Task 1 `testStreakRecalculatesAfterSettingsChange`)

- [ ] **Step 2: 계산 구현** — `HabitProgress.swift`에서 `weeklySummary(target:count:)` 함수 바로 다음(그리고 `// MARK: - 색 단계` 앞)에 붙인다.

```swift
    // MARK: - 연속 기록

    /// 오늘 기준 연속 기록. 요일 습관은 해야 하는 날 수, 주 n회 습관은 목표를 채운 주 수.
    /// 오늘(이번 주)이 아직 미완료(미달)면 끊지 않고 건너뛴다. 만든 날 이전은 보지 않는다.
    static func streak<H: HabitSchedulable>(_ habit: H, today: Date, calendar: Calendar) -> Int {
        habit.weeklyTarget == nil
            ? dailyStreak(habit, today: today, calendar: calendar)
            : weeklyStreak(habit, today: today, calendar: calendar)
    }

    /// 오늘부터 하루씩 거꾸로: 쉬는 요일은 건너뛰고, 해야 하는 날을 놓치면 멈춘다
    private static func dailyStreak<H: HabitSchedulable>(_ habit: H, today: Date, calendar: Calendar) -> Int {
        let done = Set(habit.completedDays)
        var day = calendar.startOfDay(for: today)
        var isToday = true
        var count = 0
        while DayKey.make(day, calendar: calendar) >= habit.createdDay {
            if isScheduled(habit, on: day, calendar: calendar) {
                if done.contains(DayKey.make(day, calendar: calendar)) {
                    count += 1
                } else if !isToday {
                    break
                }
            }
            isToday = false
            guard let previous = calendar.date(byAdding: .day, value: -1, to: day) else { break }
            day = previous
        }
        return count
    }

    /// 이번 주부터 한 주씩 거꾸로: 목표를 못 채운 주에서 멈춘다
    private static func weeklyStreak<H: HabitSchedulable>(_ habit: H, today: Date, calendar: Calendar) -> Int {
        guard let target = habit.weeklyTarget,
              var monday = weekDates(containing: today, calendar: calendar).first else { return 0 }
        var isThisWeek = true
        var count = 0
        while let sunday = calendar.date(byAdding: .day, value: 6, to: monday),
              DayKey.make(sunday, calendar: calendar) >= habit.createdDay {
            if weeklyCount(habit, weekContaining: monday, calendar: calendar) >= target {
                count += 1
            } else if !isThisWeek {
                break
            }
            isThisWeek = false
            guard let previous = calendar.date(byAdding: .day, value: -7, to: monday) else { break }
            monday = previous
        }
        return count
    }

    /// 2 이상이면 "🌱5", 아니면 nil (배지를 숨긴다)
    static func streakBadge(_ count: Int) -> String? {
        count >= 2 ? "🌱\(count)" : nil
    }

    /// 접근성용 "5일 연속" / "3주 연속"
    static func streakSpoken(_ count: Int, weekly: Bool) -> String {
        "\(count)\(weekly ? "주" : "일") 연속"
    }
```

컴파일 점검: `while let … , 조건 {` 문법은 Swift에서 유효하다. `weekDates`가 빈 배열이면 `guard`에서 0. `isScheduled`는 `weeklyTarget == nil`일 때만 true이므로 `dailyStreak`는 요일 습관에서만 불린다.

- [ ] **Step 2: 계산 도우미와 접근성** — `weeklyCount(of:)` 아래에 추가하고, `nameAccessibilityLabel`을 바꾼다.

```swift
    /// 오늘 기준 연속 기록 (보고 있는 주와 관계없음)
    private func streak(of habit: Habit) -> Int {
        HabitProgress.streak(habit, today: today, calendar: calendar)
    }

    private func nameAccessibilityLabel(_ habit: Habit) -> String {
        var parts = [habit.name]
        if let target = habit.weeklyTarget {
            parts.append("주 \(target)회 중 \(weeklyCount(of: habit))회 완료")
        }
        let count = streak(of: habit)
        if HabitProgress.streakBadge(count) != nil {
            parts.append(HabitProgress.streakSpoken(count, weekly: habit.weeklyTarget != nil))
        }
        return parts.joined(separator: ", ")
    }
```
