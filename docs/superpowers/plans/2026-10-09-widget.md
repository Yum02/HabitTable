# 홈 화면 위젯 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 작은 위젯(오늘 현황)과 중간 위젯(최근 4주 잔디)을 보기 전용으로 추가하고, 앱 안 미리보기 스크린샷으로 CI에서 확인한다.

**Architecture:** SwiftData 저장소를 App Group(`group.com.habittable.app`)으로 옮겨 앱과 위젯 확장이 같이 쓴다. 위젯은 저장소를 읽어 값 구조체(`HabitSnapshot`)로 바꾸고, 계산은 기존 `HabitProgress`와 새 순수 함수 `todaySummary`로 한다. 위젯 화면 뷰는 앱 타깃과 공유해서 `-widgetPreview` 실행 인자로 앱 안에 그린 뒤 CI가 찍는다.

**Tech Stack:** Swift · SwiftUI · SwiftData · WidgetKit, iOS 17, XcodeGen(`project.yml`). 로컬 빌드 불가(Windows) — 모든 확인은 push 후 GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-09-widget-design.md`

**선행 조건:** `feature/weekly-target`이 main에 합쳐진 뒤(PR #3, 춘봉이 진행 중), main에서 `feature/widget` 브랜치를 새로 만들어 시작한다.

## Global Constraints

- App Group ID는 정확히 `group.com.habittable.app`. 위젯 번들 ID는 `com.habittable.app.widget`.
- ModelContainer에는 **Habit.self와 TodoItem.self를 모두** 넣는다. 저장소를 여는 곳은 `SharedStore` 한 곳.
- 기존 데이터를 옮기는 코드는 넣지 않는다(실제 기기 사용자 없음, 사용자 확인).
- 위젯은 **보기만** 한다. 위젯에서 데이터를 쓰지 않는다.
- 색은 `Theme` 토큰만, 글꼴은 `.spoqa(...)`. 다크 모드 대응. 위젯 배경은 `.containerBackground(Theme.meadow, for: .widget)`.
- 날짜 비교는 `DayKey`, 날짜 이동은 `calendar.date(byAdding:)`. 달력은 `AppCalendar.make()`.
- UI 문구는 한국어 해요체: "오늘", "n개 남았어요", "모두 해냈어요", "오늘은 쉬는 날이에요", "습관을 추가해 보세요", "최근 4주 잔디".
- 실행 인자: `-widgetPreview`(위젯 미리보기 화면), 기존 `-seedSampleData`와 함께 쓴다.
- 컴파일 가능성을 특히 꼼꼼히 본다. 한 번 push에 한 Task씩 CI로 확인한다(사용자 확인 후 push).

## Review Focus

1. **주 n회만 있고 오늘 아직 안 함** → `0/1` "1개 남았어요"(쉬는 날이 아님). (Task 3 `testTodaySummaryWeeklyPendingCounts`)
2. **주 n회 목표를 이번 주에 이미 채움 + 오늘 안 함** → 대상에서 빠져 쉬는 날. (Task 3 `testTodaySummaryWeeklyMetIsRest`)
3. **앱에서 체크한 직후 위젯 갱신** → 저장 전에 갱신하면 위젯이 옛 값을 읽는다. 갱신 전에 `context.save()`. (Task 5 Step 2, 코드 리뷰로 확인)
4. **App Group이 안 열림** → 앱이 시작하자마자 죽는다(`fatalError`). Task 1 시험이 통과하기 전에는 Task 2로 넘어가지 않는다. (Task 1 `testAppGroupContainerIsAvailable`, Task 2 `testSharedStoreOpensGroupContainer`)
5. **만든 날 이전·습관 0개** → 만든 날 전에는 대상이 아니고, 습관이 하나도 없으면 "습관을 추가해 보세요". (Task 3 `testTodaySummaryIgnoresNotYetCreated`, `testTodaySummaryNoHabits`)

```swift
import Foundation
import SwiftData

/// 앱과 위젯이 함께 쓰는 SwiftData 저장소 (App Group 안).
/// 저장소를 여는 곳은 여기 한 곳뿐이다. Habit과 TodoItem을 모두 넣어야 @Query가 죽지 않는다.
enum SharedStore {
    static let appGroupID = "group.com.habittable.app"

    /// - inMemory: 스크린샷·미리보기용 (저장하지 않음)
    /// - readOnly: 위젯용 (읽기만)
    static func makeContainer(inMemory: Bool = false, readOnly: Bool = false) throws -> ModelContainer {
        let config = inMemory
            ? ModelConfiguration(isStoredInMemoryOnly: true)
            : ModelConfiguration(allowsSave: !readOnly, groupContainer: .identifier(appGroupID))
        return try ModelContainer(for: Habit.self, TodoItem.self, configurations: config)
    }
}
```

- [ ] **Step 2: 구현** — `HabitProgress.swift`. 타입 두 개는 파일 위쪽 `ProgressLevel` enum 바로 아래에, 함수는 `enum HabitProgress` 안 `// MARK: - 색 단계` 바로 앞에 넣는다.

```swift
/// 위젯 "오늘" 상태
enum TodayStatus: Equatable {
    case noHabits        // 습관이 하나도 없음
    case rest            // 오늘 할 것 없음
    case remaining(Int)  // n개 남음
    case complete        // 모두 완료
}

/// 위젯 "오늘" 현황 (알림과 같은 기준: 해야 하는 요일 습관 + 오늘 체크했거나 이번 주 목표 전인 주 n회)
struct TodaySummary: Equatable {
    let done: Int
    let total: Int
    let status: TodayStatus
}
```

```swift
    // MARK: - 위젯

    /// 오늘 할 것: 하루 달성률 대상(countsToward)이거나, 이번 주 목표 전인 주 n회(isWeeklyPending)
    static func todaySummary<H: HabitSchedulable>(_ habits: [H], today: Date, calendar: Calendar) -> TodaySummary {
        let targets = habits.filter {
            countsToward($0, on: today, calendar: calendar) || isWeeklyPending($0, on: today, calendar: calendar)
        }
        let done = targets.filter { isCompleted($0, on: today, calendar: calendar) }.count
        let status: TodayStatus
        if habits.isEmpty {
            status = .noHabits
        } else if targets.isEmpty {
            status = .rest
        } else if done >= targets.count {
            status = .complete
        } else {
            status = .remaining(targets.count - done)
        }
        return TodaySummary(done: done, total: targets.count, status: status)
    }

    static func todayMessage(_ status: TodayStatus) -> String {
        switch status {
        case .noHabits: return "습관을 추가해 보세요"
        case .rest: return "오늘은 쉬는 날이에요"
        case .remaining(let n): return "\(n)개 남았어요"
        case .complete: return "모두 해냈어요"
        }
    }

    /// 접근성용 문장
    static func todaySpoken(_ summary: TodaySummary) -> String {
        switch summary.status {
        case .remaining(let n): return "오늘 \(summary.total)개 중 \(summary.done)개 완료, \(n)개 남았어요"
        case .complete: return "오늘 \(summary.total)개 모두 해냈어요"
        case .noHabits, .rest: return todayMessage(summary.status)
        }
    }
```

```swift
                    .foregroundStyle(Theme.soil)
                    .monospacedDigit()
            }
            .frame(width: 84, alignment: .leading)

            if dates.count == 28 {
                Grid(horizontalSpacing: 4, verticalSpacing: 4) {
                    ForEach(0..<4, id: \.self) { row in
                        GridRow {
                            ForEach(0..<7, id: \.self) { column in
                                cell(dates[row * 7 + column])
                            }
                        }
                    }
                }
            }
        }
        .frame(maxWidth: .infinity, maxHeight: .infinity, alignment: .leading)
        .accessibilityElement(children: .ignore)
        .accessibilityLabel(percent.map { "최근 4주 평균 \($0)퍼센트" } ?? "최근 4주 기록 없음")
    }

    @ViewBuilder
    private func cell(_ date: Date) -> some View {
        let progress = HabitProgress.progress(habits, on: date, calendar: calendar)
        let level = HabitProgress.level(for: progress, date: date, today: today, calendar: calendar)
        let shape = RoundedRectangle(cornerRadius: 5, style: .continuous)
        Group {
            if level == .future {
                shape.strokeBorder(Theme.dash, lineWidth: 1)
            } else {
                shape.fill(Theme.color(for: level))
            }
        }
        .aspectRatio(1, contentMode: .fit)
        .overlay {
            if calendar.isDate(date, inSameDayAs: today) {
                shape.stroke(Theme.soil, lineWidth: 1.5)
            }
        }
    }
}
```

```swift
/// 저장소를 읽어 지금 항목 + 다음 자정 항목을 만든다 (자정에 '오늘'이 넘어감)
struct HabitProvider: TimelineProvider {
    func placeholder(in context: Context) -> HabitEntry {
        HabitEntry(date: .now, habits: [])
    }

    func getSnapshot(in context: Context, completion: @escaping (HabitEntry) -> Void) {
        completion(HabitEntry(date: .now, habits: Self.loadHabits()))
    }

    func getTimeline(in context: Context, completion: @escaping (Timeline<HabitEntry>) -> Void) {
        let now = Date.now
        let calendar = AppCalendar.make()
        let habits = Self.loadHabits()
        var entries = [HabitEntry(date: now, habits: habits)]
        if let tomorrow = calendar.date(byAdding: .day, value: 1, to: now) {
            entries.append(HabitEntry(date: calendar.startOfDay(for: tomorrow), habits: habits))
        }
        completion(Timeline(entries: entries, policy: .atEnd))
    }

    private static func loadHabits() -> [HabitSnapshot] {
        guard let container = try? SharedStore.makeContainer(readOnly: true) else { return [] }
        let context = ModelContext(container)
        let habits = (try? context.fetch(FetchDescriptor<Habit>())) ?? []
        return habits.map { HabitSnapshot($0) }
    }
}
```
