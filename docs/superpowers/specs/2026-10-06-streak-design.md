# 연속 기록 설계

## 배경과 목적

습관을 며칠(몇 주)째 이어 가고 있는지 보이면 끊기지 않게 하려는 동기가 생긴다.
세 기능(주 n회 → **연속 기록** → 위젯) 중 두 번째다. 주 n회 규칙을 따르며,
위젯은 이 계산을 그대로 가져다 쓴다. 이번 범위에 위젯과 최고 기록은 없다.

## 요구사항 (사용자 확정)

- 연속 기록은 **습관마다** 센다.
- **요일 습관은 일 단위**: 해야 하는 날(`isScheduled`)만 이어서 센다. 쉬는 요일은 건너뛰어
  끊지 않는다.
- **주 n회 습관은 주 단위**: 목표(`weeklyCount >= weeklyTarget`)를 채운 월~일 주가 몇 주
  이어졌는지 센다.
- **진행 중이면 끊지 않는다**: 오늘(요일 습관) 또는 이번 주(주 n회)가 아직 미완료면 그
  기간은 건너뛰고 어제(지난주)까지의 기록을 보여 준다. 완료하면 바로 1 늘어난다.
- 표시: 습관 이름 **옆**에 잔디 이모지 배지 `🌱5`. 단위 글자는 붙이지 않는다.
- 연속이 **2 이상**일 때만 배지를 보여 준다.
- 최고 기록은 이번에 만들지 않는다.
- 방식(요일 ↔ 주 n회)을 바꾸면 남아 있는 체크 기록을 **지금 방식으로 다시 계산**한다.
  저장하는 값은 없다(주 n회 횟수가 요일 방식 때 체크도 세는 것과 같은 원칙).

## 계산 규칙 (`HabitProgress`)

데이터 추가는 없다. `completedDays`·`createdDay`·`weekdays`·`weeklyTarget`만으로 계산한다.

| 함수 | 규칙 |
|---|---|
| `streak(h, today:, calendar:) -> Int` (새) | 아래 두 규칙 중 습관 방식에 맞는 것. |
| 요일 습관 | 오늘부터 하루씩 거꾸로 간다. `isScheduled`가 아닌 날은 건너뛴다. 해야 하는 날이 완료면 +1, 미완료면 멈춘다. 단 **오늘**이 미완료면 멈추지 않고 건너뛴다. `createdDay` 이전에 닿으면 멈춘다. |
| 주 n회 습관 | 이번 주부터 한 주씩 거꾸로 간다. `weeklyCount >= target`이면 +1, 아니면 멈춘다. 단 **이번 주**가 미달이면 멈추지 않고 건너뛴다. 주의 일요일이 `createdDay` 이전이면 멈춘다. |
| `streakBadge(_ n:) -> String?` (새) | `n >= 2`이면 `"🌱\(n)"`, 아니면 `nil`. |
| `streakSpoken(_ n:, weekly:) -> String` (새) | 접근성용 `"5일 연속"` / `"3주 연속"`. |

- 만든 주의 목표는 주 n회 규칙대로 n 그대로다(줄이지 않는다). 그래서 **만든 주에 목표를 못
  채우면 그 주는 연속에 들어가지 않고**, 연속은 다음 주부터 시작한다.
- 오늘이 쉬는 요일이면 오늘은 그냥 건너뛴다. 오늘 체크돼 있어도 +1 하지 않는다.
- 쉬는 요일에 체크된 기록(방식을 바꾸기 전 기록 등)은 요일 습관 연속에 더하지도 끊지도
  않는다.
- 요일 습관인데 `weekdays`가 비어 있으면(앱에서는 저장이 막혀 있음) 0이다.
- 미래 날짜 체크는 앱에서 생기지 않지만, 계산은 오늘 이후를 보지 않는다.
- 반복은 `createdDay`에서 끝나므로 길이는 습관 나이에 비례한다. `completedDays`는 `Set`으로
  바꿔 찾는다.
- 구현: `calendar.startOfDay(today)`에서 시작해 `calendar.date(byAdding: .day / .weekOfYear, …)`
  로 움직이고, 비교는 `DayKey`로 한다. 86400초를 빼는 방식은 쓰지 않는다(시간대·서머타임에서
  하루가 밀릴 수 있음).

## 화면 (`WeekMatrixView`)

- 이름 칸(너비 82 그대로) 안에서 `HStack { 이름 · 배지 }`. 배지에 `layoutPriority`를 주어
  이름이 길면 **이름이 먼저 말줄임**되고 배지는 항상 보이게 한다.
- 배지 글꼴 `.spoqa(11, .bold, relativeTo: .caption2)`, 색 `Theme.grass4`(다크 모드 대응 토큰).
- 주 n회 습관의 이름 아래 `weeklySummary` 줄은 그대로 둔다(배지는 이름 줄 오른쪽).
- 배지는 ‹ ›로 다른 주를 보고 있어도 **오늘 기준** 연속을 보여 준다.
- 접근성: 이름 줄 라벨 뒤에 `streakSpoken`을 붙인다(배지가 보일 때만). 화면에는 단위가 없지만
  소리로는 "일/주"를 구분해 준다.

## 샘플 데이터

`-seedSampleData`의 지난 기록이 적어도 한 습관에 2 이상 연속이 생기게 되어 있는지 확인하고,
아니면 조정한다. CI 스크린샷으로 배지를 확인한다.

## 테스트 (`HabitProgressTests`)

요일 습관:
- 해야 하는 날 연속 완료 3일 → 3, 사이에 쉬는 요일이 있어도 끊기지 않음
- 오늘 미완료면 어제까지 값 유지, 오늘 완료하면 +1
- 어제(해야 하는 날) 미완료면 오늘 완료해도 1
- `createdDay`에서 멈춤, 만든 날 이전 체크는 세지 않음
- 쉬는 요일 체크는 더하지 않음
- 오늘이 쉬는 요일이면 건너뜀(오늘 체크돼 있어도 +1 하지 않음)
- 연말 경계: 12/31 → 1/1을 넘어 이어짐
- `weekdays`가 []이면 0

주 n회 습관:
- 목표 채운 주 2주 연속 → 2, 이번 주 미달이면 유지, 이번 주 달성하면 +1
- 중간에 미달 주가 있으면 거기서 멈춤
- 월요일 경계(일요일과 다음 주 월요일은 다른 주)
- 연말 경계: 12/28(월)~1/3(일)을 한 주로 셈
- 만든 주 이전에서 멈춤, 만든 주에 못 채우면 그 주는 들어가지 않음

방식·설정 변경:
- 같은 `completedDays`로 `weeklyTarget`만 바꾸면 다른 단위로 다시 계산됨
- 같은 `completedDays`로 `weekdays`만 바꾸면 과거 날짜도 새 요일로 다시 판정됨
- 같은 `completedDays`로 목표를 3 → 2로 바꾸면 지난주도 2회 기준으로 다시 판정됨

표시:
- `streakBadge`: 0·1 → nil, 2 → "🌱2"
- `streakSpoken`: 일/주 구분

## 승인 때 정한 점 (2026-10-06)

- 요일·목표 **수정**도 다시 계산한다(방식 전환과 같은 원칙, 저장 값 없음). 월·수·금 → 화·목으로
  바꾸면 과거의 해야 하는 날도 화·목 기준으로 다시 판정되고, 주 3회 → 2회로 바꾸면 지난주들도
  2회 기준으로 다시 판정된다. 연속이 갑자기 끊기거나 늘 수 있다.
- 이름 칸은 82pt 그대로 두고, 이름이 먼저 말줄임되게 한다. 큰 글자 설정에서 이름이 너무
  짧아지면 CI 스크린샷을 보고 따로 다룬다.
- (2026-10-09 추가) CI 스크린샷에서 "물 2L 마시기"가 "물 2L 마…"로 잘려 사용자가 **이름 칸
  넓히기**를 골랐다. 목표 약 100pt. 단, 좁은 화면(폭 375pt, iPhone SE)에서 날짜 칸이 누르는
  영역 34pt보다 좁아지면 안 된다(지금 82pt일 때 SE에서 칸당 약 34.4pt로 꽉 참). 그래서 폭이
  넉넉한 화면에서만 넓히고, 좁은 화면에서는 82pt를 유지하는 식으로 칸 폭을 보장한다.
- 배지 이모지 🌱는 시스템 이모지라 다크 모드에서도 색이 바뀌지 않는다(괜찮다고 봄).
